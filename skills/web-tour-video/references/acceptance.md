# 验收清单

## 视频

- [ ] `out/final.mp4` 存在，能播放
- [ ] 首帧是完整页面，不是白屏/骨架/加载中
- [ ] 1920x1080，HEVC 视频 + AAC 音频
- [ ] 时长与录屏一致（误差 < 0.9s）
- [ ] 最后有约 800ms 空白
- [ ] 音轨每段起点与画面步骤对齐
- [ ] 字幕是 narration，不是朗读文本
- [ ] 字幕无拼音/音素标记，无裁切
- [ ] 中文字体正常，无方块字

## 画面

- [ ] 无页面报错/404/控制台错误
- [ ] 无空白页/加载中/骨架屏
- [ ] 弹窗没有意外遮挡
- [ ] 初始光标不在图表上，没有开场就弹出的 tooltip
- [ ] 向导每一步的字幕都在讲当前页，不是上一页
- [ ] 假光标每帧都在，位置合理
- [ ] 点击落点正确，按钮/输入框有响应
- [ ] 滚动/悬停/输入过程自然
- [ ] 没有点到错误元素
- [ ] 没有展示敏感数据（真实姓名/手机号/价格）

## 配音/发音

- [ ] `out/tts_texts.json` 的 ttsText 无阿拉伯数字
- [ ] narration 无拼音/音素
- [ ] `out/pron_report.md` 有每段起止和注音位置
- [ ] 多音字/品牌名/英文缩写已处理或明确列出疑点
- [ ] 品牌名读音与用户确认的一致（CMU 音素不是 IPA）
- [ ] 没有声称“已听验证”；只列人工需确认项

## 交付

- [ ] 汇报视频时长、每段起止、编码模式
- [ ] 汇报做过的修复
- [ ] 汇报仍存在的疑点
- [ ] 列出本次提交类操作产生的记录 id（如果有）
- [ ] 附 `out/pron_report.md` 和 `out/qa_report.md`
